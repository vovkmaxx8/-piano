 🎹 Virtual Piano (88 Keys) — играй на пианино прямо в консоли

> «88 клавиш — бесконечная музыка»

**Virtual Piano (88 Keys)** — это набор консольных приложений, которые превращают вашу клавиатуру в полноценное пианино.  
Программа отображает клавиши (от C4 до E6) и позволяет воспроизводить ноты с помощью клавиш `a w s e d f t g y h u j k o l p ;`.  
Звук генерируется через системные утилиты (`beep`, `winsound` или `Console.Beep`).

## 🚀 Особенности
- 🎵 17 нот в диапазоне C4–E6 (белые и чёрные клавиши).
- ⌨️ Удобная раскладка: левая рука — белые, правая — чёрные.
- 🔊 Воспроизведение звука с заданной частотой и длительностью.
- 🖥️ ASCII-подсказка с раскладкой прямо в консоли.
- 🧩 Простой ввод: нажимайте букву и слышите ноту.
- 🎨 Цветной вывод (где поддерживается).
- 📦 Кросс-платформенность: работает на Windows, Linux, macOS.

## 🛠️ Установка и запуск

Для работы требуется утилита `beep` (Linux/macOS) или `winsound` (Windows встроен).

**Установка beep (Linux):**
```bash
sudo apt install beep  # Debian/Ubuntu
sudo yum install beep  # RHEL/CentOS
На macOS можно использовать say или afplay, но в примере используется beep (требуется установка через Homebrew: brew install beep).
